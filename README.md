# 🎓 SmartStudy-AI - 10 In-Class AI Tasks Web App

A complete, modern, fast web application for students built with **React 19 + Vite + Tailwind CSS**, connected to the **Google Gemini AI API** (Free Tier) with a zero-config fallback generator.

## 🚀 10 Included Micro-AI Tools

1. **Task 1: AI Resume Builder** - Multi-field form to markdown resume preview & `.pdf` export using `jsPDF`.
2. **Task 2: AI Notes Generator** - Raw topic text to bullet-point study notes with `marked` renderer, clipboard copy, `.txt` and `.pdf` downloads.
3. **Task 3: AI Presentation Generator** - Topic input to 5-slide presentation view with Next/Prev navigation and `.pptx` export using `pptxgenjs`.
4. **Task 4: AI Syllabus Mind Map** - Converts syllabus outlines into interactive node maps with click-to-view topic detail modals.
5. **Task 5: Google Sheets as Backend** - Apps Script API endpoint interface with live data table CRUD and AI data trend insights.
6. **Task 6: AI Quiz / MCQ Generator** - Topic input to 5-10 MCQs with instant answer feedback, explanation, and score counter.
7. **Task 7: AI Subject Doubt Chatbot** - Subject selector tutor chatbot with conversation history context and clear chat option.
8. **Task 8: AI Flashcards Revision** - Generates question/answer flashcard decks with smooth 3D CSS flip animations and shuffle option.
9. **Task 9: AI Study Planner** - Form inputs (subjects, hours, exam date) to color-coded weekly study timetable grid.
10. **Task 10: AI Notes Summarizer from Photos** - Photo upload -> in-browser `Tesseract.js` OCR text extraction -> editable preview -> AI summary takeaways.
